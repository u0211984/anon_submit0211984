# TokenJoule (anonymized artifact)

This repository is the code accompanying the submission, prepared for double-blind review. To preserve anonymity, the code has been stripped of comments, documentation and history, and is packaged to reproduce all validation results in the paper. A complete, documented release will follow.

`reproduce/run_all.sh` regenerates every validation figure and number; `reproduce/README` lists the environment and expected runtime.

Includes code from RAPID-LLM [arXiv:2512.19606] (Apache-2.0) and ASTRA-sim (MIT, `astra-sim/`).
